# Lohith S. Portfolio

Starter structure for Lohith S.'s personal portfolio website.

## Structure

```text
lohith-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    ├── projects/
    ├── certificates/
    └── documents/
```

The portfolio will be built section by section. Add only real project assets,
certificates, photographs, and documents to the corresponding asset folders.
